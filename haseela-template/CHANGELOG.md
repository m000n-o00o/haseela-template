# Changelog

All notable changes to the Haseela template. Versions follow [Semantic Versioning](https://semver.org/): MAJOR for changes that break existing sites, MINOR for new features, PATCH for fixes.

## [1.0.0] - 2026-11-23

First public release.

- Static study site for GitHub Pages: today page, courses, chapter pages (explanation, slides with translation, interactive visual, terms, questions, files), question bank with spaced repetition, study planner, glossary, dark mode, offline support and progress export/import.
- Tools to prepare slides, build chapter files and PDFs, check chapters and pack a course's work.
- Approved PDF templates for the chapter summary, questions and definitions.
- `haseela-chapter` skill for Claude.
- Demo course (`DEMO`) with original sample content.
- PolyForm Noncommercial 1.0.0 license.
